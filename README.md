# 📑 MathNote Studio

Ứng dụng Desktop đa nền tảng (**Windows 10/11 & Linux**) tự động chuyển đổi file PDF bài tập Toán (Giải tích, Đại số tuyến tính,...) thành **2 file PDF chuẩn Vector LaTeX**:
1. 📖 **File Đáp Án Chi Tiết (`*_Dap_An_Chi_Tiet.pdf`)**: Lời giải đầy đủ từng bước biến đổi và kết quả cuối cùng.
2. ✍️ **File Note Tập Viết cho Bảng Vẽ (`*_File_Note_Tap_Viet.pdf`)**: Giải thích cặn kẽ mọi khái niệm/định lý/điều kiện cốt lõi, kèm **Định hướng cách làm** (không lộ đáp số, không giải hộ) và các dòng kẻ để viết trực tiếp bằng bút cảm ứng (Stylus / Drawing Tablet).

---

## 📥 Tải về bản chạy ngay (Không cần cài Python)
Vào mục **[Releases](../../releases/latest)** ở cột bên phải trang GitHub này để tải:
- 🪟 **Windows 10/11:** Tải file **`MathNoteStudio.exe`** → Nhấp đúp để chạy ngay.
- 🐧 **Linux:** Tải file **`MathNoteStudio-Linux`**.

## 🔑 Kết nối tài khoản Google AI miễn phí (Chỉ 15 giây)
1. Mở ứng dụng và bấm nút **`🔑 Lấy Mã 1-Click`**.
2. Bấm **`🌐 Mở Trang Lấy Mã Google AI Miễn Phí`** (đăng nhập bằng tài khoản Gmail sẵn có trên trình duyệt).
3. Bấm **`Create API key`** → **`Copy`**.
4. Ứng dụng sẽ **tự động bắt mã từ Clipboard**, xác thực và lưu lại cho mọi lần mở sau!
